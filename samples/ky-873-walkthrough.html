Overview

Ky gains a ky.query() shortcut for the new HTTP QUERY method, a safe, retryable way to send a request body to a read-only endpoint.

  1. Adding 'query' to requestMethods generates a ky.query() shortcut and uppercases the method to QUERY.
  2. KyInstance and RequestHttpMethod learn the new method so it type-checks.
  3. QUERY is safe and idempotent, so it joins the default retry.methods alongside GET.
